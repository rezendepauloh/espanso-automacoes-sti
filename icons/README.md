# 🎨 Diretório de Ícones do Projeto (icons)

Este diretório contém os arquivos de imagem em formato **PNG** utilizados para personalizar a identidade visual das nossas ferramentas auxiliares (Kando e CopyQ).

## 🖼️ Ícones Disponíveis

* **`format-text.png`**: Ícone associado às ferramentas de formatação automática e correção contextual de textos.
* **`lowercase.png`**: Representação visual para a automação de conversão de texto de clipboard em letras minúsculas (caixa baixa).
* **`uppercase.png`**: Representação visual para a automação de conversão de texto de clipboard em letras maiúsculas (caixa alta).
* **`microsoft-sharepoint.png`**: Logotipo oficial do SharePoint, usado em atalhos e menus circulares de abertura de pastas e diretórios de rede.
* **`stash-headset.png`**: Ícone de headset/suporte, associado a menus circulares que realizam atendimentos da STI.
* **`terminal_elevado.png`**: Ícone representativo do terminal administrativo ou comandos elevados de PowerShell.
