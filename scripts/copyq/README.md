# Integração com CopyQ

Para adicionar estes scripts ao CopyQ:

1. Abra o CopyQ.
2. Vá em `File` -> `Commands/Global Shortcuts` (ou aperte `F6`).
3. Clique em `Add`.
4. Dê um nome (ex: "Arrumar Texto").
5. No campo `Command`, cole o conteúdo do arquivo `.js` correspondente.
6. (Opcional) Defina um atalho de teclado.

Isso permitirá que você processe qualquer item do seu histórico do CopyQ usando as mesmas regras do Espanso/Kando.
