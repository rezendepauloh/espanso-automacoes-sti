# 📝 Diretório Central de Templates Textuais (scripts/textos)

Este diretório centraliza todos os arquivos de template HTML e texto puro do projeto. Cada arquivo é um modelo de e-mail ou resposta de suporte pré-definido e formatado de acordo com a identidade visual da STI.

## 📁 Subdiretórios de Categorias

* **[celular/](celular/)**: Todos os 8 modelos de respostas e instruções de problemas de suporte à telefonia celular (antiga pasta obsoleta `templates/`).
* **[bios/](bios/)**: Modelos de procedimentos para correção de problemas na BIOS (ex: BIOS HP).
* **[desempenho/](desempenho/)**: Modelos de instruções de correção para lentidões ou travamentos em computadores (`lentidao.html`).
* **[dominio/](dominio/)**: Templates para tratamento de equipamentos de informática fora do domínio institucional do MPMS.
* **[solicitacoes/](solicitacoes/)**: Modelos de requisição de fotos de equipamentos para análise de hardware à distância.
* **[telefonia/](telefonia/)**: Extensa gama de resoluções de problemas telefônicos, cobrindo cabeamento, primeira instalação, alteração de ramal, permissão de ligações e guias rápidos.
* **[viagem/](viagem/)**: Modelos de texto estruturados para pedidos e prestações de contas de diárias de viagem.
