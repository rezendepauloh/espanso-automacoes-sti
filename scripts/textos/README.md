# 📝 Diretório Central de Templates Textuais (scripts/textos)

Este diretório centraliza todos os arquivos de template HTML e texto puro do projeto. Cada arquivo é um modelo de e-mail ou resposta de suporte pré-definido e formatado de acordo com a identidade visual da STI.
