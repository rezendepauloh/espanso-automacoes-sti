# 📱 Templates de Telefonia Celular (textos/celular)

Este diretório centraliza todos os modelos HTML de respostas e comunicações oficiais para atendimentos relacionados a chips, aparelhos e linhas de telefonia celular institucional do MPMS.

## 📄 Modelos de Resposta HTML

Os arquivos abaixo são carregados de forma dinâmica pelo script de celular (`celular.py`):

* **`celular_obs.html`**: Resposta estruturada contendo blocos detalhados de observações gerais de uso de dados e roaming.
* **`celular_sem_obs.html`**: Modelo simplificado sem os blocos de observações gerais.
* **`celular_critico.html`**: Resposta para atendimentos de alta prioridade ou situações urgentes de telefonia.
* **`celular_dificuldade.html`**: Guia explicativo instruindo o usuário sobre como proceder em caso de dificuldades técnicas com sinal ou conexão de dados.
* **`celular_lembrete.html`**: Mensagem de acompanhamento ou lembrete para envio de termo de responsabilidade assinado.
* **`celular_objetivo.html`**: Mensagem pragmática e direta sobre a entrega ou liberação de uma nova linha/aparelho.
* **`celular_pos_resposta.html`**: Resposta de encerramento, solicitando feedback ou confirmação de recebimento do sinal.
* **`celular_ajuste_oxe.html`**: Template de ajuste fino de configuração interna.
