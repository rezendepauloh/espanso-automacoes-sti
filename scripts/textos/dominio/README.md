# 🌐 Templates de Máquinas Fora do Domínio (textos/dominio)

Este diretório contém modelos de orientação e respostas técnicas focados na regularização e inclusão de equipamentos de informática na rede/domínio institucional do MPMS.

## 📄 Arquivos

### [fora_dominio.html](file:///c:/Users/paulogoncalves/AppData/Roaming/espanso/scripts/textos/dominio/fora_dominio.html)
* **Função**: Resposta instrutiva para equipamentos fora do domínio.
* **O que faz**: Renderiza uma mensagem oficial informando ao usuário os riscos de manter uma máquina de trabalho desconectada do domínio (falta de atualizações de segurança, bloqueio de pastas de rede, incompatibilidade com sistemas internos) e instrui de forma passo a passo como agendar o atendimento para reinserção do computador na rede do MPMS.
