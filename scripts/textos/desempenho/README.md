# ⚡ Templates de Desempenho e Performance (textos/desempenho)

Este diretório contém modelos de e-mail e guias práticos focados no tratamento de problemas de performance, travamentos e lentidões em máquinas do Ministério Público.

## 📄 Arquivos

### [lentidao.html](file:///c:/Users/paulogoncalves/AppData/Roaming/espanso/scripts/textos/desempenho/lentidao.html)
* **Função**: Guia de suporte para computadores lentos.
* **O que faz**: Renderiza uma resposta formal orientando o usuário a realizar procedimentos de limpeza de arquivos temporários, verificação de disco, reinicialização segura, ou avisando que a manutenção da STI fará uma varredura remota de processos pesados para reestabelecer o desempenho pleno da máquina.
