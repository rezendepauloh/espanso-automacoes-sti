# ☎️ Templates de Suporte à Telefonia (textos/telefonia)

Este diretório contém uma ampla biblioteca de templates HTML de suporte para configuração, resolução de defeitos técnicos, alteração e guias de instalação de aparelhos telefônicos e ramais.

## 📄 Modelos de Suporte HTML

Os arquivos abaixo cobrem cenários frequentes mapeados no formulário `:ola`:

* **`desconectar_e_conectar_telefone.html`**: Orienta o usuário a realizar o procedimento físico básico de desligar o telefone da tomada, aguardar alguns segundos e religar para limpar falhas temporárias de rede.
* **`instalar_telefone.html`**: Guia ilustrado passo a passo sobre como conectar corretamente os cabos de rede (porta WAN/LAN) e alimentação no aparelho telefônico IP.
* **`teste_cabos.html`**: Instruções detalhadas para testar o cabeamento do ramal, verificando se há rompimentos ou encaixes frouxos no conector RJ-11/RJ-45.
* **`telefones_externos_e_interurbanos.html`**: Explica as regras institucionais e as sequências de teclas necessárias para realizar chamadas externas, celulares ou interurbanas a partir do ramal.
* **`problema_telefone.html`**: Texto padrão para registrar a necessidade de abertura de chamado técnico para troca de aparelho ou manutenção física da linha.
* **`liberacao_celular.html`**: Confirmação e termo de liberação de chamadas para celular no ramal institucional.
* **`troca_ramal.html`**: Template simplificado para confirmar a alteração do número de ramal associado ao usuário.
