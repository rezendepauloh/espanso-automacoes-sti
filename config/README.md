# ⚙️ Diretório de Configurações do Espanso

Este diretório contém os arquivos de configuração global do mecanismo do **Espanso**.

## 📄 Arquivos

### [default.yml](file:///c:/Users/paulogoncalves/AppData/Roaming/espanso/config/default.yml)
* **Função**: Arquivo de configuração padrão do Espanso.
* **O que faz**:
  * Define as configurações de comportamento globais (pesquisa, banco de dados de atalhos, etc.).
  * Habilita/desabilita o modo de expansão rápida de trechos.
  * Configura parâmetros de compatibilidade de teclado e simulação de entrada de dados (`backend`).
  * Armazena definições de inicialização do programa.
